# 实时识别优化说明

摄像头识别链路以稳定、可解释和低延迟为目标，不直接引入复杂多目标跟踪框架。

## 原始问题

整帧直接检测容易出现：

- 背景物体误检。
- 检测框在连续帧中抖动。
- 偶发误检导致类别跳变。
- 过大框覆盖整屏。
- 低阈值误报和高阈值漏检之间难以平衡。

## 当前方案

系统采用组合策略：

```text
固定 ROI -> 面积过滤 -> 中心区域优先 -> 连续帧稳定确认 -> 前端框绘制
```

## ROI 限定

摄像头默认只关注画面中央推荐区域：

```text
x=0.28, y=0.18, w=0.44, h=0.62
```

后端只保留中心点落在 ROI 内的检测结果，前端同步绘制推荐识别区域。

## 面积过滤

后端按目标框面积比例过滤异常结果：

- 小于最小面积比例的框视为噪声。
- 大于最大面积比例的框视为异常大框。

该策略可减少背景纹理、小物体和整屏误框。

## 候选框评分

候选框综合考虑：

- 模型置信度。
- 目标中心是否靠近 ROI 中心。
- 目标面积是否处于合理范围。

排序后优先返回更符合演示场景的主体目标。

## 连续帧稳定确认

后端按 `session_id` 维护轻量状态：

- 当前帧与上一帧类别一致。
- 两帧检测框 IoU 达到阈值。
- 连续出现达到设定帧数后，结果标记为稳定。

该方式能降低偶发误检对前端显示的影响。

## 前端绘制

前端在视频层上方使用独立 canvas 绘制：

- 推荐识别区域。
- 检测框。
- 类别和置信度。

视频本身不被修改，显示结构更清晰。

## 适用边界

当前方案适合单主体、近距离、演示型垃圾分类识别。若后续扩展到复杂多人、多目标长时间跟踪场景，可评估 ByteTrack、BoT-SORT 等跟踪器。
