# 从原始图片分类文件夹开始的数据清洗、标注、划分与训练详细步骤

本文档按你当前的真实情况编写：**原始数据集只有按类别分好的图片文件夹，没有 `data.yaml`，也没有任何标签文件**。  
当前类别固定为 9 类：

- `battery`
- `biological`
- `clothes`
- `glass`
- `metal`
- `paper`
- `plastic`
- `shoes`
- `trash`

也就是说，你现在拿到的数据更接近“分类图片集”，而你的毕业设计目标是**多目标垃圾检测**。因此，第一步不是直接训练 YOLO，而是先把原始分类图片集整理成可用于目标检测的数据集。

---

## 1. 先理解你当前的数据状态

你现在的原始数据集结构建议统一成这样：

```text
project_root/
├─ dataset/
│  └─ raw_classified/
│     ├─ battery/
│     ├─ biological/
│     ├─ clothes/
│     ├─ glass/
│     ├─ metal/
│     ├─ paper/
│     ├─ plastic/
│     ├─ shoes/
│     └─ trash/
├─ training/
├─ backend/
└─ frontend/
```

这 9 个文件夹里目前放的是**已经按类别分好的图片**，但这些图片：

- 还没有 YOLO 检测标签；
- 还不能直接用于多目标检测训练；
- 也没有 `train / val / test` 划分；
- 也没有 `data.yaml` 指向最终数据集。

所以接下来要做的是：

**原始分类图片集 → 数据清洗 → 人工精标核心集 → 训练种子模型 → 生成候选伪标注 → 人工校正 → 构建最终检测数据集 → 训练正式模型**

## 3. 第一步：清洗原始分类图片

因为你目前只有图片，没有标签，所以最先要做的是把原始图片质量清洗好。  
清洗对象是 `dataset/raw_classified/` 下面 9 个类别文件夹。

### 3.1 要删除的图片类型

每个类别中先人工删除下面几类图片：

1. **严重模糊、失焦、拖影明显**  
2. **目标太小，主体几乎看不清**  
3. **过曝、过暗、偏色严重**  
4. **类别本身很难判断**  
5. **完全重复或差异极小的连续拍摄图片**  
6. **与该类别明显不符的错放图片**  

### 3.2 清洗建议

- 不要追求“数量一个都不删”，要优先保留代表性图片；
- 对非常相似的图片，只留角度、背景、光照更有差异的一部分；
- 每个类别都尽量保留：
  - 不同背景
  - 不同距离
  - 不同大小
  - 不同摆放角度

如果你的总数据量在 1w+，清洗后还能保留大部分样本就够了，不需要担心删掉几百张会影响总量。

## 4. 第二步：先构建“人工精标核心集”

因为你没有任何标签，所以**不能一上来就做伪标注**。  
必须先从原始图片里抽出一批图片，人工真实框标注，作为第一版种子训练集。

### 4.1 为什么先做核心集

因为后面的伪标注质量取决于第一版模型，而第一版模型又必须依赖真实框数据训练出来。

### 4.2 核心集建议规模

对你这个本科毕设比较合适的起步规模是：

- 每类先选 **200 ~ 400 张**
- 总量先做 **2000 ~ 3500 张左右**

如果时间允许，也可以逐步扩到每类 400 ~ 600 张。

### 4.3 核心集选图原则

从 `dataset/raw_classified/` 中挑图放到 `dataset/seed_source/` 时，优先选择：

- 主体清晰；
- 目标边界相对容易画框；
- 图片内容有代表性；
- 尽量包含不同背景和尺度；
- 后期如果你自己补拍或补图，建议加入一部分**多目标场景图**。

> 注意：如果你当前原始数据基本都是“一张图一个物体”的分类图，也可以先这样起步。等种子模型训练出来后，再通过补采多目标图、手工组合场景或追加真实场景照片来增强多目标能力。

---

## 5. 第三步：人工真实框标注核心集

### 5.1 使用工具

推荐使用 **LabelImg**，导出格式选择 **YOLO**。

### 5.2 标注前先创建类别文件

你只需要这 9 类：

```text
battery
biological
clothes
glass
metal
paper
plastic
shoes
trash
```

### 5.3 标注要求

因为你的最终目标是检测，不是分类，所以标注必须按“目标检测”的要求来：

- 一个目标一个框；
- 框尽量贴近目标边界；
- 不要图省事用大框包住过多背景；
- 如果一张图中有多个目标，就每个目标分别标；
- 遮挡目标按可见主体合理框选；
- 特别小、无法判断的目标可以不标。

### 5.4 标注后的目录

人工标注完成后，把图片和标签整理成：

```text
dataset/seed_dataset/
├─ images/
└─ labels/
```

要求：
- `images/xxx.jpg` 对应 `labels/xxx.txt`
- 一个图片文件对应一个同名标签文件

---

## 6. 第四步：检查核心集标签质量

当 `seed_dataset` 标好后，先不要急着训练，先检查标签有没有明显错误。

运行：

```bash
cd training/scripts
python validate_labels.py --labels-dir ../../dataset/seed_dataset/labels --num-classes 9
```

再做统计：

```bash
python dataset_stats.py --labels-dir ../../dataset/seed_dataset/labels
```

你需要重点看：

- 是否有空标签；
- 是否有越界坐标；
- 是否有类别编号超出 0~8；
- 各类别框数量是否明显失衡；
- 是否存在某类特别少，需要再补图。

---

## 7. 第五步：划分核心集 train / val / test

核心集确认无误后，再做划分。

运行：

```bash
python split_data.py   --source-images ../../dataset/seed_dataset/images   --source-labels ../../dataset/seed_dataset/labels   --target ../../dataset/seed_dataset_split   --train-ratio 0.8   --val-ratio 0.1
```

划分后得到：

```text
dataset/seed_dataset_split/
├─ images/
│  ├─ train/
│  ├─ val/
│  └─ test/
└─ labels/
   ├─ train/
   ├─ val/
   └─ test/
```

### 7.1 划分原则

- 训练集：80%
- 验证集：10%
- 测试集：10%

其中：
- 验证集和测试集尽量从人工精标图片里来；
- 不要让未经人工校正的伪标注进入验证集。

---

## 8. 第六步：创建第一版 `data.yaml`

你原始数据里没有 `data.yaml`，所以这里需要自己生成。

如果第一轮训练使用的是核心集划分结果，那么 `training/configs/data.yaml` 应写成：

```yaml
path: ../../dataset/seed_dataset_split
train: images/train
val: images/val
test: images/test
names:
  0: battery
  1: biological
  2: clothes
  3: glass
  4: metal
  5: paper
  6: plastic
  7: shoes
  8: trash
```

> 注意：这里的 `path` 要根据你本地实际目录调整。如果训练命令是在 `training/scripts/` 下执行，通常相对路径需要仔细核对一次。

---

## 9. 第七步：训练种子模型

种子模型的作用不是追最终最高精度，而是得到一个**可以辅助后续自动出候选框**的初版模型。

### 9.1 GTX 1650 推荐参数

推荐先用：

- 模型：`yolov8n.pt`
- `imgsz=640`
- `batch=4~8`
- `epochs=50~60`
- `freeze=10`

运行：

```bash
python train_seed_model.py   --data ../configs/data.yaml   --model yolov8n.pt   --device 0   --batch 8   --imgsz 640   --epochs 60   --freeze 10
```

训练完成后，脚本会把权重复制到：

- `backend/model/seed_best.pt`

---

## 10. 第八步：准备未标图片池

种子模型训练出来后，把还没有人工标注、但你想继续利用的原始图片放到：

```text
dataset/unlabeled_pool/
```

这里面的图片可以来自：

- `raw_classified/` 中剩余未进入核心集的图片；
- 你后期新增拍摄的图片；
- 你为了增强多目标检测而补充的真实场景图片。

> 很建议你在这个阶段加入一批**多目标场景图片**，哪怕数量不多，也会对后面“一个画面识别多个垃圾物品”很有帮助。

---

## 11. 第九步：生成候选伪标注

运行：

```bash
python generate_pseudo_labels.py   --weights ../../backend/model/seed_best.pt   --source ../../dataset/unlabeled_pool   --output ../../dataset/pseudo_workspace   --conf 0.6   --imgsz 640   --device 0   --copy-images
```

输出包括：

- `pseudo_workspace/images/`：图片
- `pseudo_workspace/labels/`：候选 YOLO 标签
- `pseudo_workspace/preview/`：带框预览图

### 11.1 这里的“伪标注”是什么意思

这里的伪标注不是最终标签，而是：

- 先让模型给出候选框；
- 你再基于这些候选框做人工修改；
- 最终进入训练集的是“人工校正后的标签”。

这才是当前项目推荐的半自动标注方式。

---

## 12. 第十步：人工校正伪标注

把下面这两个目录导入 LabelImg：

- `dataset/pseudo_workspace/images`
- `dataset/pseudo_workspace/labels`

人工校正时要做：

- 删除错框；
- 补上漏框；
- 修正类别；
- 把框修到更贴边；
- 多目标图逐个目标分别标清楚。

### 12.1 优先重点检查的类别

建议优先重点复核：

- `trash`
- `biological`
- `clothes`
- `shoes`

因为这些类别通常形态变化大，更容易错。

---

## 13. 第十一步：合并生成最终检测数据集

人工校正完成后，把核心精标集和校正集重新合并，得到正式训练集。

运行：

```bash
python merge_and_split_dataset.py   --seed-images ../../dataset/seed_dataset/images   --seed-labels ../../dataset/seed_dataset/labels   --review-images ../../dataset/pseudo_workspace/images   --review-labels ../../dataset/pseudo_workspace/labels   --target ../../dataset/final_dataset   --train-ratio 0.8   --val-ratio 0.1
```

最终得到：

```text
dataset/final_dataset/
├─ images/
│  ├─ train/
│  ├─ val/
│  └─ test/
└─ labels/
   ├─ train/
   ├─ val/
   └─ test/
```

---

## 15. 第十三步：训练最终主模型

### 15.1 推荐目标

- 图片检测、论文展示：`YOLOv8s`
- 视频 / 摄像头实时识别：`YOLOv8n`

### 15.2 GTX 1650 推荐参数

#### 方案 A：最终主模型（推荐）
- 模型：`yolov8s.pt`
- `imgsz=640`
- `batch=2~4`
- `epochs=80~120`

运行：

```bash
python train_final_model.py   --data ../configs/data.yaml   --model yolov8s.pt   --device 0   --batch 4   --imgsz 640   --epochs 100
```

#### 方案 B：实时版模型
如果后面视频 / 摄像头速度不够，再用同样的最终数据集再训一个 `YOLOv8n`：

```bash
python train_final_model.py   --data ../configs/data.yaml   --model yolov8n.pt   --device 0   --batch 8   --imgsz 640   --epochs 80
```

---

## 16. 第十四步：训练完成后的使用建议

### 图片识别
优先使用精度更高的 `YOLOv8s` 权重。

### 视频 / 摄像头识别
优先使用更轻的 `YOLOv8n` 权重，配合你项目现有的：

- 多目标检测结果列表；
- 框平滑；
- 轻量跟踪；
- 类别投票；
- 连续帧稳定确认。

这样更适合 GTX 1650 环境和毕设答辩演示。

---

## 17. 一套最推荐的实际执行顺序

按顺序做：

1. 清洗 `raw_classified/` 中的原始图片；
2. 从原始图片中抽核心图片到 `seed_source/`；
3. 用 LabelImg 对核心图片做真实框标注，形成 `seed_dataset/`；
4. 检查核心标签；
5. 划分 `seed_dataset_split/`；
6. 写好第一版 `data.yaml`；
7. 训练 `YOLOv8n` 种子模型；
8. 整理未标图片到 `unlabeled_pool/`；
9. 用种子模型生成候选伪标注；
10. 人工校正伪标注；
11. 合并成 `final_dataset/`；
12. 更新正式训练用 `data.yaml`；
13. 训练 `YOLOv8s` 主模型；
14. 有需要再训 `YOLOv8n` 实时版；
15. 把最终权重放到 `backend/model/`，做图片、视频、摄像头联调。

## 18. 特别提醒

### 18.1 你当前只有分类图片集，不等于天然适合多目标检测
如果原始数据大多数都是“单物体居中图”，那它可以帮助你先训练一个能识别类别的检测模型，但对“同一张图识别多个物体”的帮助有限。

所以建议你在后续补充：

- 多目标同框图片；
- 桌面摆放多个垃圾物体的真实场景图；
- 光照变化、遮挡、尺度变化的图片；
- 视频截图帧样本。

### 18.2 验证集和测试集尽量保持人工精标
这是保证论文实验可信度的重要前提。

### 18.3 不要把未人工复核的伪标注大量混入验证集
否则指标会失真。
