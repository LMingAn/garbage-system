# 伪标注优化训练方案

## 问题定位

伪标注不能把整张图直接当作一个检测框。该方式会破坏目标框回归规律，不适合多目标检测训练。

## 推荐方案

采用半自动数据构建流程：

```text
人工精标核心集 -> 种子模型 -> 候选伪标注 -> 规则过滤 -> 人工校正 -> 正式模型训练
```

伪标注只作为人工校正起点，不能直接作为最终标签大规模混入训练集。

## 数据层级

- 人工精标核心集：训练种子模型，质量必须可靠。
- 候选伪标注集：由种子模型生成，保留高置信候选框。
- 人工校正集：人工复核后的扩充数据，作为正式训练集主要来源。
- 高置信自动保留集：模型稳定后可少量引入，比例不宜过高。

## 阶段策略

### 阶段 A：种子模型

- 模型：`YOLOv8n`
- 数据：人工精标核心集
- 目标：获得可辅助标注的初版模型

### 阶段 B：候选伪标注

- 对未标注图片生成候选框。
- 按置信度、面积、边长和宽高比过滤异常框。
- 使用 AnyLabeling 进行人工复核。

### 阶段 C：正式模型

- 模型：`YOLOv8s` 或按设备选择 `YOLOv8n`
- 数据：人工精标核心集 + 人工校正集
- 目标：生成可部署到 `backend/model/best.pt` 的模型权重。

## 验证集要求

验证集和测试集应尽量保持人工精标。未复核伪标注进入验证集会导致 mAP、Precision、Recall 失真。

## 论文表述参考

为降低标注成本并保证多目标检测标签质量，系统采用“人工精标 + 模型辅助标注 + 人工校正”的半自动数据构建策略。先使用人工精标样本训练种子模型，再用种子模型对未标注样本生成候选框，并结合置信度阈值、面积阈值和宽高比约束进行过滤。候选框经人工复核修正后，形成用于正式训练的高质量检测数据集。
